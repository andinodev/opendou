

Aquí es donde ocurre la magia de la "Latencia Cero". Necesitamos un protocolo de relevo (*Handshake*) entre el Hilo de Audio de Godot (que exige muestras cada pocos milisegundos) y nuestro Hilo de Lectura de Disco (I/O Thread).

#### 1. El Búfer Circular (Lock-Free Ring Buffer)

Para que el hilo de disco envíe datos al hilo de audio sin usar `Mutex` (lo cual causaría bloqueos y crujidos en el sonido), implementamos un *Single-Producer / Single-Consumer (SPSC) Ring Buffer* usando operaciones atómicas.

```cpp
template <typename T>
class LockFreeRingBuffer {
private:
    std::vector<T> buffer;
    std::atomic<size_t> write_index{0}; // Modificado solo por Hilo I/O
    std::atomic<size_t> read_index{0};  // Modificado solo por Hilo Audio
    size_t capacity;

public:
    // Retorna cuántos bytes se pueden leer sin sobrepasar al escritor
    size_t available_to_read() const {
        return write_index.load(std::memory_order_acquire) - read_index.load(std::memory_order_relaxed);
    }
    
    // Inserta datos (Llamado por Hilo I/O)
    void push(const T* data, size_t count);
    
    // Extrae datos (Llamado por Hilo Audio)
    void pop(T* dest, size_t count);
};

```

#### 2. El Playback Node y el Handshake (*Stitching*)

Creamos una clase personalizada que hereda de `AudioStreamPlayback`. La función `mix()` es la que Godot llama constantemente exigiendo PCM crudo.

```cpp
class BankStreamPlayback : public AudioStreamPlayback {
    StreamMetadata meta;
    const uint8_t* prefetch_ram_ptr; // Puntero al bloque cargado
    
    LockFreeRingBuffer<uint8_t> disk_ring_buffer;
    
    bool reading_prefetch = true;
    size_t prefetch_cursor = 0;

public:
    virtual void start(double from_pos) override {
        reading_prefetch = true;
        prefetch_cursor = 0;
        
        // ¡Despierta al Hilo de Disco!
        // Le pasamos el offset de disco y el puntero a nuestro RingBuffer
        IO_Thread_Pool::queue_read_task(meta.disk_offset, meta.disk_length, &disk_ring_buffer);
    }

    // Llamado por el AudioServer de Godot en tiempo real
    virtual int mix(AudioFrame *p_buffer, float p_rate_scale, int p_frames) override {
        int frames_mixed = 0;

        // FASE 1: Latencia Cero desde la RAM
        if (reading_prefetch) {
            int frames_to_read = MIN(p_frames, (meta.prefetch_length - prefetch_cursor) / sizeof(AudioFrame));
            
            // Copiado instantáneo (Memcpy)
            memcpy(p_buffer, prefetch_ram_ptr + prefetch_cursor, frames_to_read * sizeof(AudioFrame));
            
            prefetch_cursor += frames_to_read * sizeof(AudioFrame);
            frames_mixed += frames_to_read;

            // Si se acaba el prefetch, hacemos el switch silencioso
            if (prefetch_cursor >= meta.prefetch_length) {
                reading_prefetch = false;
            }
        }

        // FASE 2: Streaming desde el Disco
        if (!reading_prefetch && frames_mixed < p_frames) {
            int needed_frames = p_frames - frames_mixed;
            
            // Verificamos si el hilo de disco ya llenó el buffer
            if (disk_ring_buffer.available_to_read() >= needed_frames * sizeof(AudioFrame)) {
                disk_ring_buffer.pop((uint8_t*)(p_buffer + frames_mixed), needed_frames * sizeof(AudioFrame));
                frames_mixed += needed_frames;
            } else {
                // Buffer Underrun: El disco fue muy lento. 
                // En un motor real, aquí inyectamos silencio para no enviar basura a los altavoces.
            }
        }

        return frames_mixed;
    }
};

```

### Resumen del Flujo

1. El jugador dispara un arma.
2. `start()` se ejecuta e instruye al hilo I/O que empiece a buscar los datos en el SSD/HDD.
3. El `mix()` lee los primeros 150 milisegundos del disparo **directamente de la RAM**, garantizando respuesta instantánea.
4. Para cuando esos 150ms se agotan, el hilo I/O ya despertó, encontró el disco y llenó el `disk_ring_buffer`.
5. El `mix()` empalma (hace *stitching*) los datos del anillo circular sin que el jugador perciba ningún corte.
