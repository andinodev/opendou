Para entornos exteriores o geometría dinámica (vehículos, cajas, muros temporales) donde las Rooms no tienen sentido, dependemos del `PhysicsServer3D`. El reto aquí es el **rendimiento**: lanzar decenas de rayos (*raycasts*) por fotograma en GDScript destruye el CPU. En C++ podemos paralelizarlo.

#### 1. Raycasting Asíncrono

En lugar de forzar el cálculo en el hilo principal (`_process`), encolamos las peticiones de oclusión de cada voz activa. Durante el paso físico de Godot (`_physics_process`), interrogamos al servidor en un lote rápido.

```cpp
struct OcclusionQuery {
    Vector3 emitter_pos;
    Vector3 listener_pos;
    float current_lpf_target = 20000.0f; 
};

class OcclusionManager : public Node {
    GDCLASS(OcclusionManager, Node)
private:
    Vector<OcclusionQuery> frame_queries;

public:
    void _physics_process(double delta) override {
        // Obtenemos el estado directo del espacio físico 3D sin nodos intermedios
        PhysicsDirectSpaceState3D* space_state = get_viewport()->get_world_3d()->get_direct_space_state();
        
        PhysicsDirectSpaceState3D::RayParameters ray_params;
        ray_params.collision_mask = 1; // Solo capas acústicamente opacas (ej. Paredes)

        for (OcclusionQuery& query : frame_queries) {
            ray_params.from = query.emitter_pos;
            ray_params.to = query.listener_pos;
            
            PhysicsDirectSpaceState3D::RayResult result;
            bool hit = space_state->intersect_ray(ray_params, result);
            
            if (hit) {
                // Hay un obstáculo físico. El sonido se ahoga.
                query.current_lpf_target = 1500.0f; // Filtro Pasabajo severo
            } else {
                // Línea de visión directa
                query.current_lpf_target = 20000.0f;
            }
        }
        
        // Limpiar para el siguiente frame
        frame_queries.clear();
    }
};

```

#### 2. Aplicación y Suavizado

La acústica espacial es inestable. Si un enemigo pasa corriendo detrás de un poste delgado, el *raycast* pasará de colisionar a no colisionar en una fracción de segundo. Si aplicamos el LPF instantáneamente, el audio sonará con un *glitch*.

Dentro del `EventInstance`, el valor objetivo de oclusión (ya sea calculado por Portales o por Raycast) se somete a un filtro de interpolación antes de aplicarse al `AudioPhysicalChannel`.

```cpp
// Interpolación temporal del LPF (Slew Rate Limit)
current_spatial_lpf = Math::lerp(current_spatial_lpf, target_spatial_lpf, delta * 8.0f);

// Aplicar al canal de Godot (asumiendo que el bus tiene un efecto AudioEffectLowPassFilter insertado)
physical_channel->set_bus_effect_parameter(0, "cutoff_hz", current_spatial_lpf);

```
