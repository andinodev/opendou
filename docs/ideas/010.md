El sistema de Acústica Espacial resuelve un problema crítico de inmersión: el motor debe entender que si una explosión ocurre en la habitación contigua en *Daddy Dummie*, el jugador no debe escucharla con claridad perfecta a través de una pared de concreto sólido, sino filtrada (apagada) o propagada a través de la puerta abierta más cercana.

Dividimos este cálculo en dos niveles de detalle: **Macro-acústica (Rooms & Portals)** para interiores complejos, y **Micro-acústica (Raycasting)** para obstáculos dinámicos directos.

### `TASK-010`: Nodos `OpenDouRoom` y `OpenDouPortal`

Este sistema transforma el nivel 3D en un **grafo de propagación acústica**. En lugar de calcular la distancia en línea recta (Euclidiana), el audio viaja por los nodos del grafo, simulando la difracción.

#### 1. Definición del Grafo Espacial

Se utilizan volúmenes (basados en `Area3D`) que el diseñador de niveles coloca sobre la geometría.

* **Room:** Un volumen que representa un espacio cerrado. Contiene una lista de Portales conectados.
* **Portal:** Un volumen de intersección que conecta exactamente dos Rooms (ej. un marco de puerta o ventana). Tiene un estado de apertura (`open_factor` de 0.0 a 1.0) que afecta directamente el filtro pasabajo (LPF).

```cpp
class AudioRoom : public Area3D {
    GDCLASS(AudioRoom, Area3D)
private:
    Vector<ObjectID> connected_portals;
    // Efectos acústicos propios de la sala (Reverb)
    float reverb_decay_time = 1.5f; 
    float room_high_frequency_damping = 0.5f;

public:
    void register_portal(ObjectID portal_id);
};

class AudioPortal : public Area3D {
    GDCLASS(AudioPortal, Area3D)
private:
    ObjectID front_room;
    ObjectID back_room;
    
public:
    float open_factor = 1.0f; // 1.0 = Abierto, 0.0 = Cerrado (Muro)
    float base_lpf_cutoff = 20000.0f; // Frecuencia que deja pasar cuando está 100% abierto
    
    // Calcula qué tanta oclusión aplica basándose en su estado
    float get_current_lpf() {
        return Math::lerp(200.0f, base_lpf_cutoff, open_factor);
    }
};

```

#### 2. Cálculo de Propagación (Pathfinding Acústico)

Cuando un evento se dispara, el gestor busca en qué `AudioRoom` está el Emisor y en qué `AudioRoom` está el Listener (Cámara/Jugador). Si están en salas distintas, ejecuta una búsqueda de caminos (A* o Dijkstra) a través de los portales.
