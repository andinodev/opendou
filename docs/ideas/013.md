
El editor de audio necesita ver un "radar" de lo que está ocurriendo en el juego. Para ello, el servidor enviará (en dirección opuesta, del Juego al Editor) un paquete `MSG_TELEMETRY_DATA` a 30 FPS.

#### 1. Estructura de Telemetría

Debemos empaquetar métricas clave en un *struct* binario minúsculo para no afectar el ancho de banda.

```cpp
#pragma pack(push, 1)
struct AudioTelemetrySnapshot {
    uint32_t active_physical_voices;
    uint32_t active_virtual_voices;
    
    float total_dsp_cpu_time_ms;     // Tiempo que tomó el último _mix()
    uint32_t prefetch_ram_usage_kb;  // Cuánta RAM consumen los SoundBanks
    
    // Lista dinámica (requerirá serialización personalizada) de las voces más fuertes
    // uint32_t num_voices;
    // VoiceTelemetryData voices[];
};

struct VoiceTelemetryData {
    uint32_t event_id; // Hash del nombre
    float current_volume_db;
    Vector3 world_position;
    bool is_virtual;
};
#pragma pack(pop)

```

#### 2. Recolección y Transmisión

Al final del `_process` de nuestro `AudioEventManager`, recolectamos la información del `VoicePoolManager` y la empujamos hacia el cliente.

```cpp
void LiveUpdateServer::send_telemetry(const AudioTelemetrySnapshot& snapshot, const Vector<VoiceTelemetryData>& voices) {
    if (!editor_client.is_valid() || editor_client->get_status() != StreamPeerTCP::STATUS_CONNECTED) {
        return; 
    }

    // 1. Construir el payload binario
    int payload_size = sizeof(AudioTelemetrySnapshot) + (voices.size() * sizeof(VoiceTelemetryData));
    PackedByteArray packet;
    packet.resize(sizeof(NetworkHeader) + payload_size);
    
    // 2. Escribir Cabecera
    NetworkHeader header;
    header.message_type = MSG_TELEMETRY_DATA;
    header.payload_length = payload_size;
    memcpy(packet.ptrw(), &header, sizeof(NetworkHeader));
    
    // 3. Escribir Snapshot y Voces
    uint8_t* ptr = packet.ptrw() + sizeof(NetworkHeader);
    memcpy(ptr, &snapshot, sizeof(AudioTelemetrySnapshot));
    ptr += sizeof(AudioTelemetrySnapshot);
    memcpy(ptr, voices.ptr(), voices.size() * sizeof(VoiceTelemetryData));
    
    // 4. Enviar por TCP
    editor_client->put_data(packet.ptr(), packet.size());
}

```

### El Resultado Final

Al iniciar el juego, abres tu herramienta (escrita en GDScript o C# externamente) y te conectas a `127.0.0.1:3016`. Inmediatamente verás barras de volumen moviéndose, nodos espaciales dibujándose en 3D (gracias a `world_position`) y gráficas de consumo de CPU. Si pausas el juego desde la herramienta, puedes alterar la curva de un `AudioBlendContainer`, guardar, y al quitar la pausa, el motor del coche sonará diferente.
