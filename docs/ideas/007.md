
Mientras que los RTPCs son empujados por el juego (ej. la salud del jugador), los Moduladores **avanzan solos en el tiempo** una vez que el sonido se dispara. Operan directamente dentro de cada `EventInstance`.

#### 1. Generador de Envolvente (AHDSR)

Controla la evolución de un parámetro a lo largo del tiempo basándose en eventos de "Key On" (Play) y "Key Off" (Stop).

```cpp
enum EnvelopeState { ENV_ATTACK, ENV_HOLD, ENV_DECAY, ENV_SUSTAIN, ENV_RELEASE, ENV_IDLE };

struct AHDSR_Modulator {
    float attack_time, hold_time, decay_time, release_time;
    float sustain_level;
    
    EnvelopeState state = ENV_IDLE;
    float current_timer = 0.0f;
    float output_multiplier = 0.0f; // Va de 0.0 a 1.0

    void process(float delta, bool is_key_on) {
        if (!is_key_on && state != ENV_RELEASE && state != ENV_IDLE) {
            state = ENV_RELEASE;
            current_timer = 0.0f;
        }
        
        // Máquina de estados para avanzar el timer y calcular el multiplicador
        switch(state) {
            case ENV_ATTACK:
                current_timer += delta;
                output_multiplier = current_timer / attack_time;
                if (current_timer >= attack_time) { state = ENV_HOLD; current_timer = 0; }
                break;
            // ... lógica análoga para Hold, Decay, Sustain y Release
        }
    }
};

```

#### 2. Oscilador de Baja Frecuencia (LFO)

Genera ondas continuas para crear efectos de sirenas, trémolos (modulación de volumen) o vibratos (modulación de tono).

```cpp
enum LFOWaveform { SINE, SQUARE, TRIANGLE, SAWTOOTH };

struct LFO_Modulator {
    LFOWaveform waveform;
    float frequency = 1.0f; // Hz
    float depth = 1.0f;     // Intensidad
    
    float current_phase = 0.0f;
    
    float process(float delta) {
        current_phase += frequency * delta;
        if (current_phase > 1.0f) current_phase -= 1.0f; // Mantener fase entre 0 y 1
        
        float raw_wave = 0.0f;
        if (waveform == SINE) raw_wave = sin(current_phase * Math_TAU);
        // ... matemática para Square, Triangle, etc.
        
        return raw_wave * depth;
    }
};

```

#### 3. La Ecuación Final de Modulación

Dentro de cada `EventInstance`, antes de enviar las instrucciones finales al `AudioServer` de Godot, todos estos sistemas se combinan. Por ejemplo, para calcular el volumen final:

$Volumen_{Final} = Volumen_{Base} + \sum RTPC_{Volumen} + (AHDSR_{Salida} \times LFO_{Salida})$
